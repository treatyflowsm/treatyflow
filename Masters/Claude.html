It caters to plotting properties on an interactive map and shows where the accumulation is present. A summary table will display the total sum insured. The Tool is part of the efficient and extensive **Beyontec Suite **of products which caters to the administration of insurance functions. The Tool is however, an **independent** **tool** and can also integrate with other Insurance Business processing software (services to be written to push data from third party solutions to RA Tool). The properties are plotted as bubbles on the map and the interactive map includes all the features of Google maps such as zooming in or out and viewing a Satellite or Terrain Map along with all the other important landmarks in the region. Using just a right click, additional information for the insured property will be available such as **Sum Insured, Reinsurance details **and** Claims **paid and outstanding. The tool will be useful in depicting the total accumulated value of the sum insured for insured properties in the area. The user can also drill down to a specific area, draw a rectangle on the map and view the properties located within that area. ***2*** **CHAPTER** **1** # Overview of the Tool’s Capabilities ## Capabilities - Includes a feature to mandatorily capture the location parameters - the Latitude and Longitude of the property, at the time of issuance of insurance policies. Provision will be given to capture the location parameters in decimals or degrees. - The property location and sum insured information from the underwriting modules will be regularly (every few minutes) transferred to the Risk Accumulation tool. - The RA Tool will plot the property on an interactive map and will also display a table of Sum Insured for the region selected. - A cumulative risk definition for the given geographical area will be derived and displayed. - For deriving the Risk Exposure summary, users will be able to draw a rectangle on the very map itself to specify the geographical area. - The RA tool will enable users to view risk accumulation / exposure by means of search at different levels of hierarchy of address as defined in the structured format. The output will be shown in the following forms. - A summary representing the “Number of Risks” & “Total Exposure Amount”. - Listing of all risks with pertinent information and ability to export the same to excel. - Google map view with plotting of risk locations on map. By right-clicking the location, the users will be able to view risk details and reinsurance details. Google Map view can be presented as Terrain view and Satellite view as well. - Accumulation of policies can be represented as different color scheme to the extent as permitted by Google maps. - Integration to the licensed version of Google maps will be provided. - Representation of the exposure in appropriate Charts (for the search done) - The RA Tool can also be used as an independent tool and has the power to integrate with other Insurance Business processing software (services to be written to push data from third party solutions to RA Tool). **CHAPTER** **1** ***3*** # Functionality in detail ## Capture of location parameters - At the time of creation of quote for conversion to policy, the information for the latitude and longitude of the location of the property will also be captured. - The user will be able to select whether the location parameters are to be entered in degrees or decimals. - The location parameters will be captured for each risk covered under the policy. ## Data Upload to the RA tool - The details of the policies issued in the core system will be updated to the RA system periodically (every few minutes) using a scheduled service. - The auto upload enables the depiction of risk exposure to be nearly real time. - The data upload to the RA system can also be created manually. The Transaction -> Location Data Upload menu is provided for this purpose. ## Risk Exposure Depiction - The menu item Transaction - > Risk Exposure will be provided to access the risk exposure depiction. - A search window is provided to narrow down the area and policies for the risk exposure. The search window includes the following fields:- - Country - City : All the cities under the selected country will be listed for the user to select from. The user will be able to select multiple cities. - Accumulation type: A drop down list with values – Amber / Red / Green / Others. - Area : The user will be able to select multiple years. - UW Year - As on date - Building Name - Zone Name - Street / Road - COB : The user will be able to select multiple COBs. - Product - Location Status - Policy Number - Insured Name. - The search results will be displayed in the following formats: - List - Map - Download in excel file. - If UAE is the selected Country, all the risks within this area will be plotted on the map as shown below: - The collective exposure summary for all the selected policies will be displayed in a table and provision to download the summary will be provided. The information in the exposure summary includes ***Total Sum Insured, Total Retention and RI, Total Premium, Retention Premium and Claims paid and outstanding amounts.*** - Risks will be color coded as per the pre-configuration made:- The user will be able to view the product color details using the link in the map. - The geographical area for exposure summary can also be defined using the “draw a rectangle” feature in the map. By clicking on the feature and dragging the rectangle on the map, the risks falling within the rectangle will be retrieved and the exposure summary for the risks will be displayed. - By right-clicking on the risk, the following information will be made available:- - View Risk Details - View Risks within a Radius - Measure distance - RI Details - Total RI - Claims Details - The view risk details feature enables the user to select a risk on the map, right click and view the address, sum insured, premium paid for the risk and other information. ## Transaction Location Info This functionality enables the user to search, retrieve and browse through the entire set of policy transaction data. The system also enables the user to modify the location of a property covered in the policy. - The Search parameters include Policy#, Insured Name, Product, Geo Status, City, Area, Building, Location Status and Accuracy level. - The Search fields include ***a search as you type*** feature. For example, by typing in the Insured Name as “Knoz Al Sharq” the system will display a drop down list of all the similar insured names from the policies. The user will be able to select the exact name and search. - A list of policies matching the search criteria will be displayed. - The user can mouse over on the Insured Name to view the full name. - On clicking on the Policy number, the Policy details screen will be displayed. - The Locate/Change provided at the end of the screen will open a **M****ap ****Based Location Analysis** screen to relocate the property in the policy. - The user will be able to **click and drag** the balloon to another location. The new Latitude and Longitude coordinates will be updated and the user will be able to click on Proceed button. - From the main screen, the user will be able to **save the new coordinates**. - Similarly, provision to modify and save other key information in the policy details. ## Exposure Limit Report This functionality enables the user to view the entire Exposure, Risk and Premium, of a geographical limit for a given year. It can be viewed by **List** and on the **Map**. - The user will have the option to search for transaction data at the following levels: - - **Country** - **City** - **Area** - **Building Name** - **Zone.** After selecting the level, the user can select which year or all the years. - For example, if the user selects City, then the system will capture the Country and City from the user and display all the policies with property lying within the city boundary. - A summary will be displayed which will display the **Total Risks, Exposure and Premium**. - It will also display a split up of **New, Endorsed, Renewed** and **Cancelled** **Policies** data. - The list of policies matching the search criteria will be displayed in the window below. - The search data can also be viewed through - List - Map or - Download. - The List view will list all the policies in a scrollable window. - Using the Download option, the user will be able to export the list in an Excel file format. - The MAP view will plot all the properties on the map. The details of the policy will be displayed when clicking on the balloon. ## Risk by Accumulation Type Report This functionality enables the user to search for policies based on the Accumulation Type. - From the search window, the user will be able to select the Accumulation type from the following values: - - Amber - Green - Red - Others. - The user will be able to provide the As on date as well. - The search results include a summary which displays the **Total Risks, Exposure **and** Premium **also split up by **New, Endorsed, Renewed **and** Cancelled** Policies. - Option to view the search results in the following formats:- - List - Map - Download. - By list format, all the policies are displayed in a scrollable window. - By download, the results will be downloaded in an Excel file. - By selecting the Map, the properties will be plotted on the map using a balloon icon. - The user will be able to click on the balloon to view the details of the property, including the policy number. ## Data Download This functionality enables the user to export the transaction data from the system in an Excel file format. - The various options available for filtering and extracting the data are - Effective Date - Created Date - Active Date - Approved Date - Claims (Loss date). - The data will be exported and downloaded in an Excel file format. ## Claims Exposure This functionality enables the user to retrieve the claims exposure for a region and it is viewable through a list or plotted on a map. - The search can be carried out through Country, City, Area, UW Year, Loss Type, Loss date range, COB, Product, Insured name and by Policy number. - Based on the search parameters, the **Number ****o****f Claims****, ****Total Pa****id **and** ****Total Esti****mate** will be consolidated and displayed. - Option to view the search results in the following formats:- - List - Map - Download. - As a list, the policies will be listed in a scrollable window for the user to browse. - Option to view the claims under each policy by expanding the “+” symbol. - The user will be able to click on the Claim hyperlink to view the details of the claim and reinsurance amounts. Through a popup window, Total, Quota Share, 1st Surplus, 2nd Surplus and FAC amounts will be viewable. - As a download, the list of policies and claims will be downloaded in an Excel file format. - As a Map, the details of the claims will be plotted on the map based on the location parameters of the property in the policy. - The user can view the details of the Claim by right-clicking on the balloon. - The Claim hyperlink, when clicked on, will display the details in a popup window. Total claims amount, Quota Share, 1st and 2nd Surplus and FAC amounts will be displayed using hyperlinks. - The Summary of Exposure from the search results will be displayed in a table. - Option to download the Exposure summary in Excel file format. ## Boundary Definition Validation Where policy data is imported from third party solutions, the location parameters (latitude and longitude) will be validated against the city limits and will be defined as falling within the city boundary or outside the city boundary. **CHAPTER** **1** ***4*** # Masters The various key aspects of the system used in the Risk Exposure Depiction can be maintained using the Masters Module. This section lists the various Masters provided in the Risk Accumulation Tool. ## Company Information A list of Insurance Companies, their information, Address, Division and Department details will be maintained in this Master. - Provision to add new company details. - Provision to right click on the Company Id and Edit or Delete the company information. ## Address Details Address definition and maintenance can be carried out through this master. ## Risk Classification The master list of Risk Classifications can be carried out through this master. ## Location Limit Definition The Location Limit will be defined in the system for different locations using this master. ## Common Id Maintenance List of values used in the Transaction screens can be maintained using this master. ## Currency Management The list of Currencies and the exchange rates will be maintained using this master. ## Boundary Management The boundary for each City will be defined using this master. The user can specify the latitude and longitude of the North East and the South West points. ## Accumulation Risk Type Maintenance The Accumulation Risk Type Maintenance master will be used to define the Risk Types and their Accumulation Levels. **CHAPTER** **1** ***5*** # Admin The various functions pertaining to User Management and related details will be maintained in this section. ## Password Profile Multiple Password Profiles will be created and maintained using this screen. The Password Profiles created here will be available and applied in the User Management screen. - Details about Password Profiles include minimum and maximum length, password format whether Alpha/Alphanumeric, permitted characters, first character and last character, minimum lower case and upper case characters and password expiry days. ## User Groups User Groups will be created and will be assigned to individual user logins. - Provision to select access to Applicable Menus. Effective date range for each menu will be captured from the user. ## User Creation User logins will be created and maintained using this screen. - The User Creation tab will capture details about the user such as his full name, the applicable Password Profile and User Group. - The email address will also be captured. - All the available Roles will be listed to select and apply. Multiple roles can be applied to the user. - The applicable Branch and Department will also be captured. - When a new user is created, an email will be sent to the user containing the login userid and password. The user will be able to login and the user will be prompted to change the password. ## Menu Hierarchy The entire list of Menus, Sub-Menus and Functions will be maintained using this screen. - A new Function can be included by selecting the Main Menu and Sub Menu. - Similarly, a new Sub Menu or a new Main Menu can be included into the system. ## Update Geo Address A Geo Address can be uploaded into the system using this screen.
